이 배포는 [qrer321/ffxiv-patch](https://github.com/qrer321/ffxiv-patch)의 fork 배포입니다. 원본의 마지막 변경(패치 제거·백업 복구 결과에 이전 버전 index 안내 추가)까지 모두 포함하고, 아래 변경을 더했습니다.

### 캐릭터 선택창 한글 표시 수정

- 현재 위치의 지명 일부 글자가 `=`로 보이던 문제를 고쳤습니다(예: `안=빛 마을` → `안갯빛 마을`).
- 생일의 `별빛`이 `별-`로 보이던 문제를 고쳤습니다.
- 종족·부족·생일·수호신·직업 등 큰 라벨의 한글이 현재 위치 줄보다 1.5배 크게 보이던 것을 같은 크기로 줄이고, 한글 아랫선을 숫자에 맞췄습니다(`레벨 100 사무라이`).

### 인게임 장식용 글꼴의 한글 크기·위치 조정

- 창 제목(자유부대·링크셸·임무 찾기 등)의 한글이 지나치게 크던 것을 본문과 같은 한글 글꼴로 바꾸고, 영문·숫자와 세로 가운데를 맞췄습니다.
- 자유부대·기술 목록 왼쪽 탭과 기술 목록·캐릭터 창 직업명의 한글을 본문 크기로 줄이고 숫자 기준선에 맞췄습니다.
- 링크셸 목록 `링크셸1 :`, 기술 목록 `레벨 100`처럼 작은 숫자가 한글 옆에서 아래로 쏠려 보이던 것을 세로 가운데에 맞췄습니다.
- 숫자·영문은 글로벌 원본 글꼴을 그대로 씁니다.

### 게임 업데이트 대응

- 이전 게임 버전의 index 차단을 텍스트(`0a0000`)에 더해 폰트(`000000`)·UI(`060000`)에도 적용합니다. 사전 점검과 패치 생성 모두 해당합니다. UI index는 항목이 많아 사전 점검이 몇 초 더 걸릴 수 있습니다.
- 게임 업데이트로 창 구조가 바뀌어 일부 창의 UI 보정(파티 보너스 역할명, 임무 찾기 역할 탭, 소지품 창 부제 간격)이 검증에 실패해도 패치 생성 전체가 멈추지 않습니다. 그 보정만 글로벌 원본으로 두고 작업 로그에 경고를 남깁니다.

**사용 방법**
- 이전 패치를 쓰고 있었다면 **패치 제거 → 패치** 순서로 다시 적용해 주세요. 폰트를 새로 만들어야 바뀐 한글 표시가 반영됩니다.

**확인 상태**
- 릴리즈 빌드가 경고 0개·오류 0개로 완료됐고, 배포 EXE에 내장된 제너레이터·폰트 패키지·RSV 맵의 해시가 빌드 입력과 같음을 확인했습니다.
- 7.58 clean 데이터 사본으로 패치를 생성해 로비 한글 할당 실패 0, 글꼴 검증 항목에 새 실패가 없음을 확인했습니다.
- 실제 게임(UI 100%)에서 캐릭터 선택창 지명·생일·큰 라벨, 인게임 창 제목, 링크셸 목록·`레벨 100` 표시를 확인했습니다. 인게임 탭·직업명과 UI 150% 이상 화면은 실제 게임에서 따로 확인하지 않았습니다.
- 창 구조가 바뀐 UI 보정을 건너뛰는 동작은 회귀 테스트로만 확인했고, 실제 게임 업데이트로는 확인하지 않았습니다.
